## 部署（約 5 分鐘）
1. 新增一份 Google 試算表 → 擴充功能 → Apps Script → 貼上 `Code.gs`。
2. 專案設定 → 指令碼屬性 → 新增 `PRINCIPAL_PASSCODE`（校長密碼）。老師密碼不在這裡設，在試算表 `Teachers` 分頁（見下）。
3. 部署 → 新增部署 → 網頁應用程式 → 執行身分「我」、存取「任何人」→ 複製網址。
4. 把網址貼到 `config.js` 的 `SEL_GAS_URL`（三個頁面共用），推上 GitHub Pages。
5. 另開一個 Apps Script 檔，貼上 `RosterSeed.gs` → 執行 `seedRoster` 一次 → 刪除該檔。名單只存在你的試算表（Roster 分頁），之後增減學生可直接改分頁，或用看板「📋 班級名單」。

未設定 `GAS_URL` 時為展示模式，資料只存在該裝置，方便試玩。

## 自我圖式（動物頭像，選一次就固定）
- 學生點自己的座號後，從 **30 種動物**（小狗、小貓、小兔、小熊、貓熊、狐狸、老虎、獅子、青蛙、猴子、企鵝、小雞、小豬、乳牛、綿羊、無尾熊、浣熊、貓頭鷹、小鴨、河馬、大象、長頸鹿、斑馬、小鹿、刺蝟、老鼠、倉鼠、野狼、章魚、烏龜）選一隻代表自己，顯示在座號下方。插圖是自繪向量圖（`animals.js`），每台裝置看起來都一樣。
- **每個號碼只能選一次，選了就固定，不能再換**；點選後會先跳出「確定選『老虎』嗎？」確認，按「確定」才會儲存。
- **每隻動物同班只能一位同學使用**：同班已被選走的變灰、後端也會擋，兩人搶同一隻時畫面會提示重選。
- 選錯或要重選：**老師（自己班）或校長**在老師看板點該學生 →「重設圖案」，該學生可以再選一次。也可以直接清空試算表 Roster 的「圖案」欄。
- 圖案代號仍以 emoji 存進試算表（例如 🐶），所以舊資料相容；動物清單在 `animals.js`。

## 點心情就是送出（不需要再按「送出」）
- 流程：**點座號 → 點一個心情＝直接送出**，沒有另外的「送出」按鈕，也**沒有留言框**（為了讓同學一個接一個、一次到位）。
- 還沒點座號就點心情：不會送出，提示列會閃動提醒先點號碼；連點只會送出一筆。
- **點錯了**：手機的完成頁有「↩︎ 按錯了，重選」，按下會撤銷剛剛那一筆並回到同一位同學重新選（送出後 **3 分鐘內**、僅該座號今天最新的一筆）。**大螢幕沒有撤銷按鈕**（按下就完成）；要更正請老師到試算表 Checkins 分頁刪除那一列。已寄出的即時通知信無法收回。
- 想改回「選好再按送出」：把 `config.js` 的 `window.SEL_AUTO_SUBMIT` 改成 `false`。

## 反應速度（大螢幕一個接一個點）
- **點下去畫面立刻換下一位**，不等伺服器回應（Google 約 1～2 秒）；簽到資料放進佇列，在背景依序送出，座號格的「✓ 已Check-in」也是立刻出現。
- 前一位的回應回來時，**不會清掉下一位剛點的座號**（舊版在網路慢、同學排隊連點時會，可能漏記簽到）。
- 網路不穩時自動重試（最多 6 次，間隔 1～5 秒）；每筆帶一個 `reqId`，後端同一個 `reqId` 只寫入一次，**重試不會重複寫入**（避免回應遺失時被當成第二次簽到）。
- 全部重試都失敗才會在畫面左下角出現紅色提示，並把該座號格標紅（「X 號的簽到沒有成功，請再點一次」）；網路正常時完全不會出現任何提示。若還有未送出的簽到就關閉網頁，瀏覽器會先警告。
- 後端（`Code.gs`）簽到時只讀試算表**最後 400 列**，不再讀整張表，資料越多越明顯。

## 大螢幕模式（教室白板／投影）
- 螢幕寬度 ≥ 900px（或網址加 `?board=1`）自動啟用：**座號在左、心情卡片緊鄰在右、送出鈕在旁邊**，整個流程在同一個畫面內完成，不用捲動。
- 版面會**依目前視窗高度自動縮放**，座號與心情都放進同一個畫面不用捲動（視窗大小、瀏覽器顯示比例不同都適用）。
- 同學一個接一個點：點座號 → 點心情，**按下就完成**。送出後畫面立刻回到初始狀態，下一位同學馬上可以點；沒有任何提示、視窗或動畫（座號格上會留著「✓ 已Check-in」「✓✓ 今日完成」的狀態標記，方便看誰還沒簽到）。
- 大螢幕不會自動跳出選動物視窗，也**不顯示「你選了 X 號」和動物小圖**（點完座號直接進行下一步）；還沒有動物的座號，**格子角落有一個小小的 🎨**，點它才會開啟選動物（點格子本體只選座號，避免誤觸打斷流程）。

## Check-in／Check-out，與當天心情變化
- **不論時間，只看順序**：學生當天**第一次送出＝👋 Check-in**，**第二次送出＝🏁 Check-out**，由後端依當天紀錄自動判定（前端不傳、也不採用任何類型），學生不需要選擇，畫面也完全沒有「早上／放學」或時間相關的字樣。
- 學生點自己的號碼後，畫面預告「👋 今天第一次：Check-in」或「🏁 今天第二次：Check-out」；圖卡顯示「✓ 已Check-in」「✓✓ 今日完成」。第三次以後視為「更正 Check-out」（統計取最新一筆）。
- 試算表 Checkins 新增「類型」欄（Check-in／Check-out）。**舊試算表不用手動改**，第一次簽到時後端會自動補上標題；沒有「類型」的舊資料，依「同一位學生當天的第幾筆」推算（第 1 筆＝Check-in，之後＝Check-out）。
- **當天心情變化**（同一天 Check-in、Check-out 都有簽到者）分四類：**好轉**＝非綠→綠、**持平**＝顏色不變、**轉換**＝非綠→另一種非綠、**轉差**＝綠→非綠。
- 老師看板「今日」：每位學生顯示「👋 臉 → 🏁 臉」與變化標記，並有「今日心情變化」摘要（轉差的排最前面）。校長總控台表格也有 Check-in／Check-out／變化三欄。
- 統計（短／中／長期）新增「當天心情變化」：好轉／持平／轉換／轉差的人數與比例、逐日（逐週）變化圖、Check-in 與 Check-out 的情緒分布、各班 Check-in／Check-out 簽到率與好轉／轉差人次。持續關注名單也會納入「當天由綠轉差 3 次以上」。
- **一週預警**：最近 7 天情緒持續不佳的學生（連續 3 次以上非綠、簽到 5 次以上且負向 60% 以上、紅色 3 次以上、當天由綠轉差 3 次以上，任一條件）會
  ① 顯示在老師看板與校長總控台「今日」畫面最上方的橘色預警框；② 寄 Email 給該班導師（Teachers 分頁「信箱」）與校長（指令碼屬性 `PRINCIPAL_EMAIL`）。
  Email 由定時觸發器每天（週一至週五）下午 4 點左右檢查，同一位學生 3 天內只通知一次。**啟用方式**：Apps Script 編輯器選 `setupWeeklyWarning` 執行一次（會要求授權）；想立刻試跑選 `weeklyWarningNow`。
- **統計圖表**（老師看板、校長總控台的「趨勢統計」與全校報告共用）：情緒分布圓餅圖（全部／Check-in／Check-out）、情緒走勢長條圖與折線圖、各班情緒組成長條圖；期間可選 7／30／180／365 天（長期以週為單位）。
- **全校報告（校長）**：校長總控台「📄 全校報告」分頁，可切換每天（今天）、每週（最近 7 天）、每月（最近 30 天），自動產生重點摘要、參與率、當天心情變化、各班比較、情緒排行、持續關注名單；「🖨 列印／存成 PDF」可直接輸出。資料來自既有的 `stats`，不需更動後端。
- **清除當天資料（僅校長）**：校長總控台右上「🗑 清除全校當天資料」，或點開某班後按「🗑 清除此班當天資料」。依畫面上選的日期清除簽到與當天處遇紀錄，清除後學生可重新 Check-in。刪除的列會先備份到試算表 `Deleted` 分頁。老師沒有此功能。
- 為保護隱私，學生頁**不會**顯示任何人（包含自己）另一次的心情；變化只有老師與校長看得到。
- 匯出 CSV：Check-in 顏色／情緒、Check-out 顏色／情緒、當天變化。
- 即時通知：同一位學生 Check-in、Check-out 各最多通知一次。

## 即時通知導師（Email）
學生一按送出，導師幾秒內就會收到 Email（手機 Gmail 會跳通知）：
- **紅色**一律通知（因為已沒有留言框，藍色、黃色不會觸發通知）；同一位學生 Check-in、Check-out 各只通知一次。
- 收件人：Teachers 分頁該班的「信箱」欄（請用學校 Google 信箱）。可在「專案設定 → 指令碼屬性」另設 `PRINCIPAL_EMAIL`（校長副本）、`DASHBOARD_URL`（信裡的看板連結）。
- 信裡只有班級、座號、姓名、情緒，**不含留言內容**；詳細內容要登入看板。
- 第一次使用：在 Apps Script 編輯器選 `testAlert` 執行一次，授權寄信權限並確認收得到測試信，再重新部署新版本。
- 寄信失敗或額度用完都不會影響學生簽到。

## 情緒統計（短／中／長期）
兩個看板都有「📈 趨勢統計」分頁，可切換：**短期 7 天、中期 30 天、長期 180 天（約一學期）**。
- 內容：簽到人次、負向情緒（紅＋藍＋黃）占比與前一期比較、情緒走勢堆疊圖（30 天內逐日、更長逐週）、情緒排行、各班比較與參與率（校長）、**持續關注學生**。
- 持續關注條件（任一）：連續 3 次以上非綠色、簽到 5 次以上且負向占 60% 以上、紅色 3 次以上。門檻在 `Code.gs` 的 `stats_()`。
- 每位學生每天只取最新一筆；老師只能統計自己的班，校長可選「全校」或單一班級。
- 期間長度由網址參數 `days` 決定（1–400），按鈕在 `stats.js` 的 `RANGES`。

## 權限與隱私
- **學生頁只顯示座號，不顯示姓名**；後端依座號從 Roster 補上姓名。
- **老師**：用 `Teachers` 分頁的班級密碼登入，後端只回傳該班資料（即使改網址也看不到別班）。一位老師帶多班，就在該分頁填多列、同一組密碼。
- **校長**：用 `PRINCIPAL_PASSCODE` 登入 `principal.html`，可看全校含姓名。
- 試算表本身請只分享給校長；`Teachers` 分頁內有各班密碼。

## 需要依學校調整
- `EMOTIONS`（index.html）：12 種情緒，`tier` 1/2/3 對應低/中/高年級（堆疊），各歸屬紅藍黃綠一色；`COLORS`：4 色的緩和策略；
- 只在週一至五開放（`SCHOOL_DAYS`），放假日填 `HOLIDAYS`；`SIGNALS`：辰光五手勢的圖與說明。
- 看板的「優先關心」：紅色，且尚未記錄處遇。

## 隱私提醒
試算表含學生個資，只分享給授課教師；密碼為全校共用，建議定期更換。
